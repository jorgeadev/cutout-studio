# Support

cutout-studio is maintained as an open-source project. Community support is best-effort, and response times are not guaranteed.

## Before asking for help

1. Read the README, especially Quick start, Deployment, and Troubleshooting.
2. Search existing issues for the exact error or behavior.
3. Reproduce the problem with the latest code or deployed version.
4. Collect the browser, operating system, selected model, processor, and relevant console output.

## Where to ask

- Reproducible defect: use the **Bug report** issue form.
- Usage, setup, or deployment help: use the **Question or help** issue form.
- Product improvement: use the **Feature request** form.
- Documentation problem: use the **Documentation improvement** form.
- Security vulnerability: follow [SECURITY.md](SECURITY.md) and report it privately.

Please do not request support through unrelated issues or pull requests.

## Protect your data

Issues are public. Never attach private photographs, credentials, access tokens, browser profiles, or unredacted logs. Use the included sample image, generated content, or a sanitized minimal reproduction.

## Support scope

The community can reasonably help with:

- Running and building this repository
- Supported processing and export options
- Browser console errors and reproducible UI problems
- COOP/COEP deployment configuration
- Contributions that stay within the project's architecture and privacy goals

Support may not be available for:

- Private forks or heavily modified deployments
- Custom model training
- Third-party hosting configuration without a reproducible repository example
- General browser, GPU driver, or operating-system troubleshooting
- Legal advice about AGPL compliance or third-party licensing
